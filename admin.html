🎫 수상 건별 PIN 발급·관리

PIN은 발급 순간에만 표시됩니다. 전달 전 반드시 복사해두세요. 같은 사람이 여러 상을 받으면 시상 건마다 개별 발급하세요.

동일한 시상 종류로 여러 PIN을 발급합니다. 발급된 PIN 원문은 이 브라우저 탭에서만 임시 보관하며, 새로고침하면 복구할 수 없습니다. 발급 직후 인쇄하거나 CSV로 안전하게 보관해 주세요. 실제 사용 전 테스트용 발급 건과 구분하세요.

수상자(등록명)시상상태발급 일시선택 확정관리

기존 선택을 취소해도 사용한 PIN은 자동 복구되지 않습니다. 필요하면 새 PIN을 발급하세요.
